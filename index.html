💡 What Is ferrite?

ferrite is a program that lets a modern AI language model — Qwen 3.5 — run directly on your own computer. Most AI tools you have used before send your questions to a large server farm somewhere on the internet and then send the answer back to you. ferrite does the opposite. Everything happens on your own machine.

The program was written from scratch in a programming language called Rust, which is known for being both very fast and very safe. Instead of relying on a graphics card to do the heavy lifting, ferrite is specially tuned to squeeze maximum speed out of an ordinary computer processor — the same chip that has been sitting in laptops for years. That tuning includes support for AVX-512, a set of modern processor instructions that let a chip do many calculations at once, along with a technique called speculative decoding that lets the model produce text faster without cutting corners on quality.

The result is a tool that feels responsive. Text appears on screen at roughly the speed you would read it — around 90 tokens per second on hardware that most people would consider old. There is no waiting several seconds for a paragraph to appear.

⚡ Why ferrite Feels Fast

Speed in AI software usually comes from expensive hardware. ferrite takes a different approach and gets its performance from careful engineering instead.

  • Hand-tuned for processors. The engine is written to take advantage of AVX-512 instructions, so compatible chips can process many numbers in a single step rather than one at a time.
  • Speculative decoding. A small, quick helper model guesses the next few words, and the main model checks those guesses in one pass. When the guesses are right — which is often — you get several words for the price of one.
  • No wasted motion. Because ferrite was written from scratch rather than assembled from generic parts, there is very little overhead between your keystroke and the first word appearing.
  • Light on memory. The engine is designed to work comfortably on laptops that do not have enormous amounts of RAM.

🧰 What You Need

ferrite is built for everyday Windows computers. Before you begin, make sure your machine roughly matches the following:

  • Operating system: Windows 10 or Windows 11, 64-bit.
  • Processor: A modern multi-core Intel or AMD processor. AVX-512 support gives the best results, but the engine still runs without it.
  • Memory: 8 GB of RAM is enough to get started; 16 GB gives you more room to work.
  • Storage: A few gigabytes of free space for the application and the model files it uses.
  • Graphics card: Not required. This is the whole point of ferrite.

🎛️ Getting the Best Speed

ferrite is already tuned to run well out of the box, but a few small habits help it stay fast:

  • Close heavy background apps. Web browsers with dozens of tabs and video editors compete for the same memory ferrite needs.
  • Keep your laptop plugged in. Many laptops slow their processor down on battery power to save energy. Plugging in usually restores full speed.
  • Choose the balanced or performance power plan. In Windows settings under System, Power, you can select a plan that lets the processor run at its full rate.
  • Leave some free disk space. Keeping a few gigabytes free helps the operating system manage memory efficiently.
  • Ask shorter questions when you want quicker replies. Very long prompts take longer to process before the first word appears.

🔧 If Something Goes Wrong

The download does not start.

Refresh the releases page and try clicking the file again. Some browsers block downloads until you confirm them in a toolbar prompt at the top of the window.

Windows will not let me open the program.

This is the standard Windows protection message for newly downloaded software. Choose “More info” and then “Run anyway” to continue.

Responses appear more slowly than expected.

Check that your laptop is plugged in, close other large programs, and confirm your power plan is not set to a battery-saving mode. Older processors without AVX-512 support will run more slowly than the reference laptop, which is normal.

The program closes right after opening.

Restart your computer, then open ferrite again. Restarting clears leftover memory from other applications and resolves most first-launch problems.
